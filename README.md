# LiangYou IconLibrary

良友媒体图标库，供支持 `name / description / icons` 格式的播放器导入。

## 订阅地址

```text
https://raw.githubusercontent.com/MaddestAlistar/LiangYou-IconLibrary/main/LiangYou-Emby-Icons.json
```

当前收录 **2,104** 个图标索引（2026-09-24 整理）。五个第三方来源原计 2,179 条，按图片 URL 去重后保留 2,099 条，并加入 5 个良友专属图标。同名但图片地址不同的样式均予保留，重名项附有来源名称，便于选用。

## 良友专属图标

内置 5 个良哥看未来专属图标，文件保存在 `icons/liangyou/`，并置于订阅列表开头，方便搜索使用。
