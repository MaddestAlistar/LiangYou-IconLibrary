## 维护约定

1. 订阅前 5 项固定为：`良友-流云音乐`、`良友-CarPlay`、`良友-3ayne虎影`、`良友-Player`、`良友-熊猫`。更新时不得改变其名称、地址、文件或排列顺序。
2. 新增图标按 URL 和可核对的图片内容去重；同名不同款式使用数字编号，不再把来源项目名称添加到图标显示名称中。
3. 已有编号保持稳定；补充同名款式时使用空闲编号，不因排序或重新同步而整体重编号。
4. 显示名称的整理不得删除图片中的作者标记，不得将第三方图片重新标为本库原创。新增来源的必要声明继续记录在本文件中。
5. 提交前检查 JSON 可解析、名称与 URL 无重复、5 个专属图标置顶，并核对图片数量及地址没有意外变化。

6. 每次更新后，以全部图标为整体重新排序：固定前 5 个专属图标，其余按名称 A–Z 排列，中文按拼音并入且忽略大小写；字母比较忽略空格、标点和连接符，独立数字片段按自然数顺序比较，例如 `A24 01`、`A24 02`、`A24 5` 不合并为单个数字。纯符号名称排在字母之后，数字开头的名称全部置于最末并按自然数顺序排列。排序只调整位置，不改名称、已有编号或图片地址。
